# crates/csi-driver

CSI controller service and shared CSI bootstrap.

Responsibilities:

- Implement CSI Identity and Controller services.
- Integrate with Kubernetes CSI sidecars.
- Register existing TrueNAS filesystem datasets as volumes.
- Optionally create new filesystem datasets through a backend API hook.
- Refuse authoritative dataset deletion unless explicitly enabled.
- Track controller publish assignments by volume and node.
- Expose SMB, snapshot, retention, and replication metadata in driver-owned
  volume state.
- Serve generated CSI gRPC bindings over a Unix socket.

Out of scope:

- Block volumes.
- NFS subdirectory provisioning.
- Direct libvirt or QEMU manipulation.

CSI protobuf bindings are generated by `crates/csi-proto` at build time.
